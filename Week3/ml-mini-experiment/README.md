# ML Mini-Experiment: Compare Model Architectures/Algorithms

## Overview

This project is a machine learning mini-experiment that compares the performance of multiple classification algorithms using the Iris dataset. The objective is to evaluate different models based on their classification accuracy and understand their strengths and limitations.

## Objective

- Compare different machine learning classification algorithms.
- Train and evaluate each model on the same dataset.
- Measure and compare their prediction accuracy.
- Analyze the performance of each algorithm.

## Dataset

- Iris Dataset (built into Scikit-learn)
- Number of Samples: 150
- Number of Features: 4
- Number of Classes: 3

## Algorithms Compared

- Decision Tree
- Random Forest
- K-Nearest Neighbors (KNN)
- Logistic Regression
- Support Vector Machine (SVM)

## Technologies Used

- Python 3
- Pandas
- Scikit-learn
- Matplotlib
